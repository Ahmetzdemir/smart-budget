# Smart Budget - Kişisel Bütçe & Harcama Takibi 💳

Smart Budget, gelir ve giderlerinizi yönetip, kategorilere göre harcamalarınızı görsel grafikler üzerinde görebileceğiniz bütçe panelidir.

## 🛠️ Özellikler
- **Dinamik SVG Donut Grafik:** Harcama kategorilerini ve oranlarını anlık olarak güncellenen dairesel SVG halka parçalarıyla çizer. (Kütüphanesiz, saf matematik formülleri kullanılmıştır).
- **Bütçe Limiti Uyarısı:** Aylık harcama limitinizi belirleyip, bu limitin doluluk oranını renk değiştiren uyarı barlar üzerinden takip etme.
- **Filtreleme & Arama:** Gider ve gelir işlemlerinde kelime bazlı arama yapma ve işlem tiplerine göre listeyi süzme.
- **Kalıcı Veri:** Tüm verileri `localStorage` üzerinde saklama.
- **Light & Dark Tema:** Göz dostu karanlık veya aydınlık arayüz seçeneği.

## 💻 Kullanılan Teknolojiler
- **Yapı:** HTML5 (Dynamic SVG rendering)
- **Tasarım:** CSS3 (Custom UI form variables, Flexbox & Grid, Dark/Light Mode)
- **Mantık:** JavaScript (ES6+, LocalStorage state)
- **İkonlar:** Lucide Icons

## 🚀 Nasıl Çalıştırılır?
Doğrudan `index.html` dosyasını tarayıcınızda açarak anında harcama kaydetmeye başlayabilirsiniz.
